# Документація ufo-tech/rest-bundle

rest-bundle публікує методи [JsonRpcBundle](https://github.com/ufo-tech/json-rpc-bundle) як REST API. RPC-метод лишається єдиною реалізацією: параметри, валідація, безпека, кеш, події та документація беруться з ядра RPC; бандл додає HTTP-маршрути, REST-формат запитів і відповідей та документи OpenAPI/Postman.
