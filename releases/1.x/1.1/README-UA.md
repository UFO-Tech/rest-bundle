# 1.1 — Кілька REST-входів для API-груп

Теги: 1.1.0. Перший реліз: 2026-10-15.

## Головне

- **API-групи**: REST-маршрути імпортуються окремо для кожної групи; кожен вхід має власні методи, версії, документи OpenAPI і Postman та провайдер токенів.
- **Імена маршрутів із префіксом групи** (`internal_ufo_rest_doc`), старі імена лишаються аліасами для `general`.
- **Коректна HTTP-семантика**: `405` для неправильного методу, `HEAD` обслуговується `GET`-маршрутами, `400` для некоректного JSON-тіла.

## Що нового

### Входи для груп

```yaml
rest:
    resource: ../../vendor/ufo-tech/rest-bundle/config/router.yaml
    prefix: /rest
    trailing_slash_on_root: false

rest_internal:
    resource: ../../vendor/ufo-tech/rest-bundle/config/router.yaml
    prefix: /internal
    defaults: { api_group: internal }
    trailing_slash_on_root: false
```

Методи розподіляються між групами атрибутом `#[RPC\APIGroups]` (JsonRpcBundle 10.2). Щоб метод з'явився в REST, йому також потрібен `#[Route]`. Префікс URL не залежить від назви групи; імпорт без `api_group` належить до `general`. Одну групу можна імпортувати двічі з різними `name_prefix`.

### Безпека для групи

REST використовує конфігурацію безпеки RPC: `protected_api` для викликів, `protected_doc` для документації і `security.providers` для перевірки токенів окремо в кожній групі.

### Запити

- Параметри об'єднуються в такому порядку: змінні маршруту, query, поля форми, JSON-тіло; пізніші ключі перемагають.
- З `Content-Type: application/x-www-form-urlencoded` тіло читається лише як поля форми.
- JSON-тіло, що не є об'єктом чи масивом, повертає `400`.
- Службові атрибути маршруту (`api_group`, `ver`, `_rest_route`, …) не передаються як параметри.

## Зміни та виправлення

- `x-ufo.environment` сервера OpenAPI більше не містить `fromCache`; `RestServiceMap::isFromCache()` видалено.
- Кожен REST-маршрут отримує запасний маршрут `<route>_method_not_allowed`, тож неправильний метод повертає `405` з problem details.
- Запити ізольовані в довгоживучих воркерах: пул RPC-подій скидається на кожен запит.

## Нотатки з оновлення

- Потрібні PHP 8.4 і `ufo-tech/json-rpc-bundle` ^10.2.
- Імена маршрутів мають префікс групи; генеруйте URL за новими іменами або користуйтеся аліасами `general`.
- Клієнти, що надсилали некоректне JSON-тіло, тепер отримують `400`; клієнти з неправильним HTTP-методом — `405` замість `404`.
